# Welcome to AetherRSI

This folder is the **workspace**. The file tree on the right shows only what is inside it.

## Try it

1. Click a paragraph here: it becomes a quote chip `@1` under the message box.
2. Type `Summarize @1` and press **Send** (pick 🔁 Echo to try it without an LLM).
3. Open `hello-app` with ▶ Open: a folder that is an app.

## What is where

| Thing | Where |
|:--|:--|
| Previews and agents | `extensions/<id>/aether.json` |
| Apps | any folder with an `aether.json` of kind `app` |
| Your data | `~/.aether-rsi/` (never inside the core) |

> Write `/slow` in a message to the Echo agent to try ↪ Inject and ⏹ Stop.
